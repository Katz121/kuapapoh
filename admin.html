🛡️ ระบบบันทึกและป้องกัน Git ทับข้อมูล (Persistence & Sync)

ตั้งค่าการบันทึกข้อมูลเพื่อให้การแก้ไขของทีมคงอยู่ตลอดไป ไม่ถูกลบหรือเขียนทับเมื่อมีการ Git Push โค้ดใหม่

💡 ทำงานอย่างไร:

เมื่อคุณกด "บันทึกการเปลี่ยนแปลง" ข้อความ ฟอนต์ และรูปภาพทั้งหมดจะถูกจัดเก็บใน Local Storage ทันที และหน้าเว็บหลัก (index.html) จะดึงข้อมูลล่าสุดนี้ไปแสดงผลเสมอ แม้ว่าโปรแกรมเมอร์จะทำการ `git pull` หรือ `git push` โค้ด HTML ใหม่ก็ตาม ข้อมูลที่ทีมกรอกไว้จะไม่โดนทับ

☁️ การเชื่อมต่อ Cloud Storage (แนะนำสำหรับทีมหลายคน)

คุณสามารถเชื่อมต่อกับบริการจัดเก็บ JSON ฟรี เช่น JSONBin.io หรือ Cloudflare KV Worker เพื่อให้ทีมงานทุกคนเห็นข้อมูลตรงกันทันที

⚠️ คืนค่าเริ่มต้น
