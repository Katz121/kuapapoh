# กั่วป่าโพ้ จีโชว์เมือง

เว็บแนะนำโครงการพื้นที่สร้างสรรค์ย่านเมืองเก่าตะกั่วป่า จังหวัดพังงา
ภายใต้โครงการ Creative Cultural District (CCD) · สนับสนุนโดย CEA · ร่วมดำเนินงานโดย สจล.

เว็บ static ล้วน ไม่มี build step · เปิดดูโดยดับเบิลคลิก `index.html` หรือ deploy ทั้งโฟลเดอร์ได้เลย

## Deploy บน Cloudflare Pages

เชื่อม repo นี้แล้วตั้งค่า:

- **Framework preset:** None
- **Build command:** เว้นว่าง
- **Build output directory:** `/`

## โครงหน้า

1. **Hero** พื้นเหลือง ชื่อโครงการ + อาคารลายเส้นสามหลัง + ปุ่มสำรวจพื้นที่/เปิดแผนที่
2. **สามพื้นที่หลัก** บ้าน 78 · 109 · 305 · ภาพลายเส้นเป็นภาพหลัก ภาพถ่ายจริงห้อยเป็นการ์ดเล็กที่มุม
3. **แถบลาย** ลายตัวอักษรจากโปสเตอร์คั่นส่วน
4. **ที่มาของชื่อ** "กั่วป่า" + "โพ้" พร้อมภาพเก่าจากเอกสาร
5. **แนวคิด 6 อ.** พื้นน้ำเงินเข้ม
6. **POH SHOP (โพ้ช็อป)** ของที่ระลึกสร้างสรรค์และงานคราฟต์ชุมชน
7. **ติดต่อ** พื้นชมพูมาเจนต้า
8. **Footer** เครดิตโครงการ + ลิงก์เอกสารต้นฉบับ

## ที่มาของเนื้อหา

ส่วนที่มาของชื่อ · สามพื้นที่ · 6 อ. ถอดจากเอกสารของโครงการโดยตรง
วันงานและชื่อแทร็กมาจากโปสเตอร์ · ปี 2569 มาจากโพสต์ของเพจ
ข้อมูลติดต่อมาจากหน้า About ของเพจ ไม่ใช่จากเอกสาร

## ยังรอข้อมูล

- **ตารางวันที่ 16 สิงหาคม** ยังไม่ประกาศ (ในเว็บขึ้นกล่องแจ้งไว้ในส่วนตารางกิจกรรม)
- **ข้อมูลสำหรับผู้มาเยือน** ค่าเข้า · วิธีจองเวิร์กช็อป · ที่จอดรถ · วิธีเดินทาง
- **เชื้อสายของสมาคมบ้าน 109** เอกสารเขียน "ฮากก้า จีนแคะ" แต่ป้ายบนอาคารเขียน 廣東會館 (กวางตุ้ง) · เว็บใช้ตามเอกสารไปก่อน

## หมายเหตุทางเทคนิค

- ฟอนต์โหลดจาก Google Fonts · ถ้าโหลดไม่ได้จะตกไปฟอนต์ไทยของระบบ layout ไม่พัง
- เนื้อหาอ่านได้แม้ปิด JavaScript (scroll reveal ทำงานผ่านคลาส `.js` เท่านั้น)
- มี JSON-LD schema.org/Event สำหรับผลการค้นหา


## ระบบจัดการเนื้อหา (CMS Admin)

เข้าสู่ระบบจัดการเนื้อหาได้ที่: dmin.html (รหัสผ่านเริ่มต้น: 78109)

- **แก้ไขเนื้อหาทั้งหมด:** ข้อมูลทั่วไป, Hero, สามพื้นที่, ที่มาของชื่อ, 6 อ., โพ้ช็อป & สินค้า, ข้อมูลติดต่อ
- **ระบบป้องกัน Git ทับข้อมูล (Anti-Overwrite):** ข้อมูลที่ทีมแก้ไขจะถูกบันทึกผ่าน LocalStorage / Cloud Storage และดึงไปแสดงผลบน index.html อัตโนมัติ แม้ว่าจะมีการ git pull หรือ git push โค้ดใหม่ ข้อมูลที่ทีมแก้ไขจะไม่สูญหาย
- **สำรองและกู้คืน:** สามารถ Export / Import ไฟล์ .json ได้ในคลิกเดียว
